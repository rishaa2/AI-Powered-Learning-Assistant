# LearnEasy – AI-Powered Learning Assistant 📚🤖
LearnEasy is a smart educational platform designed to support students through AI-driven tools. The system provides automatic content summarization, intelligent Q&A generation, coursework chat support, and emotional assistance through facial expression recognition.

🔧 Tech Stack
Backend: Python, FastAPI, Langchain, Gemini API, Sutra LLM (for multilingual support – Hindi & Bengali)

Frontend: React.js

Database: MongoDB

AI/ML: TensorFlow, Keras, OpenCV, scikit-learn, CNN, ImageDataGenerator

Utilities: NumPy, Pandas, Matplotlib, TQDM

🚀 Features
📄 PDF Summarization & Q&A Generator
Automatically extracts key points from study materials and generates relevant questions using Gemini LLM via Langchain.

💬 Coursework Chatbot
Provides academic assistance through natural language queries using FastAPI and LLM integration.

😊 Facial Emotion Detection
Detects and interprets real-time emotional states via webcam using a CNN-based model, offering supportive interactions.

🌐 Multilingual Support
Supports Hindi and Bengali using Sutra LLM to make learning more inclusive.
